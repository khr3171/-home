# 한걸음의 진심
부산형 경계선지능인 지원사업 홈페이지 제작 초안.

## 화면 확인
이 폴더의 **index.html**을 Chrome 또는 Edge로 열면 됩니다. 설치나 빌드가 필요하지 않습니다.
휴대전화에서도 사용할 수 있는 스크롤형 페이지입니다.

## 파일
- index.html: 홈페이지 내용
- styles.css: 색상, 글씨, 반응형 디자인
- script.js: 글씨 확대, 신청 안내, 메뉴 표시
- site-config.js: 두 프로그램의 실제 신청 주소
- assets/hero.png: 새로 생성한 메인 일러스트
- CONTENT-SOURCES.md: 자료 출처와 운영 전 확인 사항

## 구글 폼 신청 주소 연결
site-config.js를 메모장이나 코드 편집기로 열고 각 url의 빈 따옴표에 **https://로 시작하는 실제 주소**를 넣으세요.

```js
window.SITE_CONFIG = {
  diagnosis: { url: "https://forms.gle/실제검사신청주소", label: "진단검사 신청하기" },
  education: { url: "https://forms.gle/실제교육신청주소", label: "자립교육 신청하기" }
};
```

위 예시 주소는 설명용입니다. 반드시 실제 주소로 교체하세요.
주소를 저장하면 버튼이 새 창으로 신청서를 엽니다. 접수가 끝나면 주소를 비우세요.
주소가 없는 프로그램은 '신청 준비 중' 안내가 표시됩니다.
이 홈페이지 자체에서는 개인정보나 신청서를 받거나 저장하지 않습니다.

## GitHub Pages에 올리기
1. GitHub에 새 저장소를 만드세요.
2. 이 폴더의 파일과 assets 폴더를 올리세요. index.html은 저장소의 맨 위에 있어야 합니다.
3. 저장소의 Settings → Pages → Build and deployment에서 **Deploy from a branch**를 선택하세요.
4. Branch는 **main**, 폴더는 **/(root)**를 선택하고 Save를 누르세요.
5. GitHub에서 표시하는 홈페이지 주소로 접속하세요.

상대 경로를 사용하므로 저장소 이름이 붙는 GitHub Pages에서도 작동합니다.
이 작업에서는 원격 저장소 생성과 공개 배포를 하지 않았습니다.

## 운영 전
- 신청 대상, 모집 일정, 선정 기준, 서류, 문의처를 확정해 추가하세요.
- 협약기관이 확정되면 '협약 확정 전' 문구와 기관 정보를 수정하세요.
- 효원상담원의 방문 장소를 담당자에게 확인하세요. 다른 자료에는 문창회관 프로그램실도 나옵니다.
- 심리치유·학습지원 교육비는 요청하신 대로 향후 안내할 지원으로 구분했습니다.
- 신청 시작과 함께 footer의 제작 초안 문구를 실제 운영 문구로 수정하세요.
- 타 기관 현재 모집 여부와 중복 지원 조건은 담당자에게 확인하세요.
- 큰 글씨 버튼, 키보드 이동, 휴대전화 화면, 실제 신청 링크를 확인하세요.

- 일경험 예시: 바리스타, 디자인, 여행사, 도배·장판. 모두 기관 발굴·협약 전입니다.

- 첫 화면에서 상담 안내창을 열 수 있습니다. 현재 051-000-0000은 임시 번호이며 전화 연결 버튼은 표시하지 않습니다.

### 실제 상담 번호 설정
site-config.js의 contact.number를 실제 번호로, contact.isTemporary를 false로 바꾸세요.
실제 번호가 입력되면 안내창에 전화 연결 버튼이 표시됩니다.
현재 예시 번호 051-000-0000은 연결되지 않습니다.

### 일경험 기관을 추가할 때
index.html에서 id="experience"인 영역의 카드를 수정하거나 복사하세요.
기관이 확정되면 '연계 준비 중'을 바꾸고 기관명·장소·연락처·일정·참여방법을 넣으세요.
확정되지 않은 예시를 신청 가능한 프로그램처럼 표시하지 마세요.
